N.I.N.A. offers a broad range of capabilities to automate your imaging run.
To do so there are two different approaches available.

## Approach 1

[The Legacy Sequencer](./simple/simple.md)
This interface, also called the Legacy Sequencer in existing settings and files, provides a compact target list for a fixed number of images. It supports common startup, target preparation, autofocus, guiding, dithering, meridian flip and shutdown options. Internally it builds the same sequence entities as the Advanced Sequencer and can convert the current plan with **Build Sequence**.

## Approach 2  
[The Advanced Sequencer](./advanced/advanced.md)  
The Advanced Sequencer supports specialized equipment and workflows through explicit instructions, containers, loop conditions and triggers.
Instead of restricting the user to a specific workflow, the workflow itself can be customized to specialized requirements with simple building blocks that can be arranged together.
